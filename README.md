# 🚀 BSM Business Management

A modern Flutter-based Business Management application built for small and medium businesses to simplify daily operations like billing, ledger management, quotations, delivery tracking, and customer handling.

BSM helps businesses manage everything in one place with a clean UI, fast performance, and scalable backend architecture.

---

# ✨ Features

## 📄 Billing & Invoicing

* Create professional invoices
* Generate and manage quotations
* Convert quotations into final bills
* Payment status tracking
* Invoice history management

## 👥 Customer Management

* Add and manage customers
* View transaction history
* Search and filter customers easily
* Maintain customer records efficiently

## 📒 Ledger Management

* Credit & debit tracking
* Outstanding balance management
* Payment updates
* Financial history records

## 🚚 Delivery Management

* Delivery tracking system
* Delivery status updates
* Delivery history maintenance

## 📊 Business Utilities

* Dashboard overview
* Responsive modern UI
* Real-time updates
* Optimized performance

# ⚡ Getting Started

## Clone Repository

```bash
git clone https://github.com/yuvanchanthar/bsm-business-management.git
```

## Navigate to Project

```bash
cd bsm-business-management
```

## Install Dependencies

```bash
flutter pub get
```

## Run Application

```bash
flutter run
```

---

# 🔧 Backend Setup

## Install Backend Dependencies

```bash
npm install
```

## Start Backend Server

```bash
node server.js
```

## Environment Variables

Create a `.env` file:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
DB_NAME=your_database_name
NODE_ENV=production
```
